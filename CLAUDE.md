## 1. What this site is

The practice page, under the owner's own name, and only that (studio decision
D-2026-10-21-19; owner pick 2026-10-23). One reader: an engineering lead at a
robot maker who decides in twenty seconds whether to book a call. The h1 is the
owner's pitch, verbatim: "When an autonomous robot fails in ways your logs
don't explain, I find the real cause and prove it, independently." The flagship
is incident investigation on the hard cases; the recurring offer is a release
check. The worked example stays the public demo repo
`github.com/thrmnn/ros2-localization-triage`. No studio name in public.

The personal portfolio is theoalessandro.com, a separate repo
(`~/Perso/thrmnn.github.io`). Superseded 2026-10-23: the two sites now link to
each other (the .com's Practice card and hero button; here, one footer line).
One identity line with dated stints is allowed here; no CV section, no
research, no publications.

## 2. Non-negotiables (the build gate enforces most of them)

- `npm run preflight` is the canonical gate (`.claude/verify-cmd`): clean
  build, `astro check`, `scripts/check-build.mjs`, og byte-compare. Run it on a
  frozen tree before any push; read its grouped output.
- No em dash anywhere in rendered output (the gate fails on the character).
- Two private names are forbidden in rendered output, commit messages, file
  names and alt text; the gate carries them base64-encoded so the list is not
  itself the leak. Never write them in plain text in this repo.
- No `theoh-io`, no phone number, no price on the landing. The 2,200 EUR
  sentence lives only on the unlinked `/audit` route, held on local branch
  `hold/audit-route`, never pushed until the owner says the post day has passed.
- Every number on the page comes from `public/data/stata-*.json` (all written
  by `scripts/sample-stata-replay.py` from the demo repo) or from the demo README
  verbatim. Re-audit against the demo's HEAD before every
  merge; the demo has withdrawn a headline number once already (1,880).
- Never fabricate a value. Placeholder plus a flag, never a plausible guess.
- No new npm dependency without the owner's approval.
- No `git add -A` while agent worktrees exist under `.claude/worktrees/`.

## 3. How work lands

Work on a branch `cycle-YYYYMMDD/<slug>`, push the branch freely, stage the
preview (`PREVIEW_BASE=/ch/ npx astro build --outDir dist-preview`, then
`~/Perso/site-review/scripts/push.sh`; it serves at
https://preview.theoalessandro.com/ch/), send the owner a contact sheet, and
merge to `main` only on the owner's word.
