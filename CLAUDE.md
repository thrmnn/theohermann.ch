# theohermann.ch — agent guardrails

Read this before touching the repo. The site is LIVE at https://theohermann.ch
(GitHub Pages from `main`, public repo `thrmnn/theohermann.ch`, DNS and the
`theo@theohermann.ch` mailbox at Infomaniak). Every push to `main` deploys.

## 1. What this site is

The robotics consulting landing page, and only that. One reader: a buyer who
runs ROS 2 fleets and decides in twenty seconds whether to reply to a cold
email. It sells one scoped engagement (ROS 2 fleet log triage) on the evidence
of the public demo repo `github.com/thrmnn/ros2-localization-triage`.

The personal research portfolio is theoalessandro.com, a separate repo
(`~/Perso/thrmnn.github.io`). The two sites never link to each other from a
page a peer or a buyer reaches. Do not add research, publications, or the
personal biography here.

## 2. Non-negotiables (the build gate enforces most of them)

- `npm run preflight` is the canonical gate (`.claude/verify-cmd`): clean
  build, `astro check`, `scripts/check-build.mjs`, og byte-compare. Run it on a
  frozen tree before any push; read its grouped output.
- No em dash anywhere in rendered output (the gate fails on the character).
- Two private names are forbidden in rendered output, commit messages, file
  names and alt text; the gate carries them base64-encoded so the list is not
  itself the leak. Never write them in plain text in this repo.
- No `theoh-io`, no phone number, no price on the landing. The 2,200 EUR
  sentence lives only on the unlinked `/audit` route, held on local branch
  `hold/audit-route`, never pushed until the owner says the post day has passed.
- Every number on the page comes from `public/data/stata-replay.meta.json`
  (generated by `scripts/sample-stata-replay.py` from the demo repo) or from
  the demo README verbatim. Re-audit against the demo's HEAD before every
  merge; the demo has withdrawn a headline number once already (1,880).
- Never fabricate a value. Placeholder plus a flag, never a plausible guess.
- No new npm dependency without the owner's approval.
- No `git add -A` while agent worktrees exist under `.claude/worktrees/`.

## 3. How work lands

Work on a branch `cycle-YYYYMMDD/<slug>`, push the branch freely, stage the
preview (`PREVIEW_BASE=/ch/ npx astro build --outDir dist-preview`, then
`~/Perso/site-review/scripts/push.sh`; it serves at
https://preview.theoalessandro.com/ch/), send the owner a contact sheet, and
merge to `main` only on the owner's word.

## 4. Settled rulings, do not reopen

- Public repo (owner, 2026-09-08). Repo visibility is a disclosure question and
  is asked on its own if it ever comes up again.
- Landing without a price; audit route unlinked and noindex.
- Hero = the real Stata PR2 replay with its explanation beside it; the trail is
  AMCL's estimated path, never "the robot's path"; never "faults found".
- Robot names and ROS terms stay unglossed where the copy is README-verbatim.
- No clients, no testimonials, no availability line.

The durable history of decisions is in the owner's memory notes and in
`~/Perso/site-review/docs/` (spec8-phase2, spec9-ch*, ruling9-ch).
